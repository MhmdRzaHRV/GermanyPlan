# My Germany

نسخه ساده و شخصی برنامه مدیریت آماده‌سازی سفر و مهاجرت به آلمان.

## اجرا

در پروژه React فعلی، محتوای پوشه `src` و فایل `public/service-worker.js` را جایگزین کنید و سپس:

```bash
npm start
```

## امکانات

- داشبورد و میزان پیشرفت
- کارها با واجب / مورد نیاز، توضیح، تاریخ و آدرس
- مدارک با وضعیت اصل و کپی
- وسایل با واجب / مورد نیاز و تعداد
- ثبت هزینه با ریال / یورو و تاریخ
- یادآور و اعلان مرورگر بدون نصب پکیج
- نمایش سفر بعد از فعال‌کردن خرید بلیط
- حالت تاریک
- ذخیره اطلاعات در LocalStorage

فایل مدارک داخل برنامه آپلود نمی‌شود و اطلاعات این نسخه فقط در مرورگر نگهداری می‌شود.

## استفاده آفلاین

1. نسخه جدید را با `npm run deploy` منتشر کنید.
2. یک بار سایت را در Chrome/Edge با اینترنت باز کنید و صبر کنید کامل بارگذاری شود.
3. سپس می‌توانید اینترنت را قطع کنید؛ Service Worker فایل‌های برنامه را برای بازدیدهای بعدی کش می‌کند.
4. برای نصب مثل اپ، از منوی مرورگر گزینه Install app یا Add to Home Screen را انتخاب کنید، اگر مرورگر آن را نشان می‌دهد.

نکته: پس از انتشار نسخه جدید، یک بار آنلاین سایت را باز کنید تا فایل‌های نسخه جدید دریافت شوند. اطلاعات برنامه در همان مرورگر و همان دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های سایت می‌تواند آن‌ها را حذف کند.
